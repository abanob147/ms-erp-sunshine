# MS ERP — Sunshine Import & Export (Starter)

هذه حزمة بداية قابلة للنشر، وليست نظام ERP مكتملًا بعد. تتضمن تسجيل دخول Supabase، شاشة الشحنات المستوردة، وشاشة الأصناف الأساسية.

## 1) إعداد Supabase
1. افتح مشروعك في Supabase.
2. من SQL Editor اختر New query.
3. انسخ محتوى `schema.sql` وشغّله.
4. من Authentication > Users أنشئ مستخدمًا للمدير بالبريد الذي زودتنا به، وضع كلمة مرور بنفسك.
5. من Authentication > Settings عطّل Allow new users to sign up (التسجيل العام).
6. من Project Settings > API انسخ Project URL وPublishable key (أو anon public key). لا تستخدم service_role key.

## 2) نشر الملفات
1. أنشئ مستودعًا جديدًا في GitHub وارفع إليه `index.html` و`schema.sql` (يمكن رفع README أيضًا).
2. في Vercel اختر Add New > Project ثم Import Git Repository.
3. اختر المستودع واضغط Deploy. لا تحتاج Build Command؛ هذا موقع HTML ثابت.
4. افتح رابط Vercel بعد النشر.

## 3) أول تشغيل
1. افتح رابط الموقع.
2. في شاشة إعداد الاتصال أدخل Project URL وPublishable/anon public key.
3. اضغط حفظ الاتصال على هذا الجهاز.
4. سجل الدخول بالبريد الذي أنشأته في Supabase وكلمة المرور التي وضعتها هناك.

## تنبيهات مهمة
- لا ترسل كلمة المرور أو مفاتيح سرية عبر المحادثة.
- لا تضع `service_role` key في الموقع أو GitHub.
- سياسات RLS تسمح للمستخدمين المسجلين فقط بالوصول؛ عطّل التسجيل العام وأنشئ حساب المدير فقط. عند إضافة الموظفين لاحقًا يجب تطوير نظام أدوار وصلاحيات قبل إنشاء حساباتهم.
- هذه نسخة أولية وليست نظام محاسبة متكاملًا. لا تشمل بعد المبيعات والمشتريات والقيود المحاسبية وحركات المخزون والتقارير والنسخ الاحتياطي المتقدم.
- أسعار الصرف وإدارة العملات ليست مفعلة في هذه النسخة، رغم أن العملة الأساسية المستهدفة EGP.
